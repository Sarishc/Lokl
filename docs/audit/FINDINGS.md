## Note on LOKL-022's re-rating

The prior audit rated this P1. Reconsidered per the remediation owner's explicit prompt: this is a marketplace where a buyer and seller meet in person to exchange goods, chat is the pre-meetup communication channel, and "block user" is the only self-service safety control offered before that in-person meetup happens. A safety control that visibly exists in the UI (button, confirmation toast) but has zero effect is worse than not offering the feature at all, because it gives users false confidence going into an in-person transaction. Rated Critical.
